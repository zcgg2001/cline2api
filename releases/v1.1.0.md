# Cline2API v1.1.0

本版修复后台改密与角色权限、账号数据保存、Anthropic 工具调用，并统一本地构建版本号。保留 v1.0 的 Free / Pass 分组和 API Key 授权行为。

## 修复与改进

- 账号管理接入官方 ClinePass 三窗口额度、个人余额、最近账单实际扣费和订阅标价；未知、未订阅、失败缓存与实际零值分别展示。
- 同账号额度查询共享短期缓存和凭据刷新互斥；财务信息仅管理员可读，查询不改变账号调度状态。
- 账号管理新增状态概览、搜索筛选与排序、卡片/列表切换、分页、跨页勾选和详情侧栏。
- 批量测试/刷新显示逐项进度和错误，支持停止后续任务；可修改分组、导出或删除所选账号，普通用户维持只读权限。
- 批量删除与分组保存失败时回滚，账号页资源独立维护并嵌入二进制。
- 修改密码更新当前用户的实际登录凭据；需要验证当前密码，禁止清空密码。
- 后台会话绑定用户；改密、管理员重置密码及删除用户撤销对应会话。
- 普通用户只读查看账号、统计、模型和请求日志，可修改自己的密码；用户、Key、凭据导出和配置管理仅管理员可用。
- 无法删除最后一个管理员；新建用户默认普通角色，拒绝非法角色。
- 新密码使用 bcrypt；兼容旧 SHA-256 密码，成功登录后自动升级（旧密码超过 72 字节时保留兼容验证，需手动改密）。
- 本机初始 `admin / admin` 登录后必须修改密码；远程部署可通过 `CLINE_ADMIN_PASSWORD` 初始化默认管理员。
- 账号文件采用同目录临时文件、同步和原子替换；解析失败或读取失败时停止启动并保留原文件。启动迁移前备份为 `.cline-accounts.json.bak`。
- 代理配置返回独立快照，防止后台修改请求头与请求转发并发读写同一个 map。
- Anthropic 流式工具调用完整累积参数，支持并行工具调用与独立内容索引；断流、上游错误或无效参数不再报告正常完成。
- 保留 Anthropic 非流式工具调用结果，不再清空 `tool_use` 内容。
- 端口冲突由正常绑定错误报告，启动时不再终止占用端口的其他进程；`-start` 转发指定地址与端口。
- 新增 `VERSION` 文件，CLI、桌面端与 Docker 默认使用 `v1.1.0`，仍可通过构建参数覆盖。
- Docker 挂载整个数据目录，默认仅映射本机端口；PR 与发布构建先运行测试。

## 升级注意

- 升级前备份现有配置。备份文件仍含 refreshToken，不要提交或随安装包分发。
- 已有非默认密码保持有效，普通用户从本版起不再拥有管理权限。
- 使用默认 `admin / admin` 的账号只能从本机登录并改密；Docker/远程初始化请设置 8–72 字节的 `CLINE_ADMIN_PASSWORD`。该变量只初始化仍使用默认密码的 admin，不覆盖已经设置的密码。
- Docker 用户先停止旧容器，将原有配置和可选 `override.md` 复制到 `./data/`，然后使用新版 Compose。旧的单文件挂载不支持原子替换。
- 空 API Key 列表仍允许匿名代理请求；对外部署前请生成 Key。
- 本版聚焦上述问题，Responses 协议全面兼容、全链路取消/超时、账号刷新合并及前后端目录拆分留待后续版本。
