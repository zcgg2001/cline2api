# Cline2API v1.0.0

本版新增后台用户管理、Free / Pass 分组隔离，并修复 OAuth 登录后无法识别订阅类型的问题。

## 新增功能

- 后台登录门禁、用户管理、密码重置及中英文界面。
- 固定 Free / Pass 两组账号，支持手动设置与批量修改。
- API Key 可授权 Free、Pass 或两组。
- Chat Completions、Messages、Responses 三种协议统一执行分组权限。
- 模型列表按 Key 授权过滤，账号导入导出保留订阅类型。
- 请求日志保存订阅快照，后台显示分组账号数和用量。
- OAuth 登录查询 Cline 计划接口，自动识别 Free / ClinePass，后台显示结果。

## 修复

- 重试、账号切换、冷却恢复和免费模型降级始终遵守 Key 的授权范围。
- 授权组内没有可用账号时明确报错，不会越组调度。
- 删除全部账号时保留用户、Key、模型和监听设置。
- 账号池状态更新与持久化增加并发保护。
- OAuth 状态轮询使用快照，避免并发读写。
- 代理环境测试改为独立进程，避免缓存导致测试顺序依赖。

## 升级注意

- 升级前备份 `.cline-accounts.json` 等本地配置，配置和账号凭据不会上传 GitHub。
- 旧账号迁移为“待确认”，不会凭空认定为 Free 或 Pass；需要在后台确认后才能参与调度。
- 旧 Key 兼容迁移为两组授权；可在后台缩小授权范围。
- OAuth 订阅检测失败时保留“待确认”，不会误授权。
- 默认管理员凭据为 `admin / admin`，部署后应立即修改密码。
- 当前用户角色字段不代表完整的后台细粒度权限隔离。
