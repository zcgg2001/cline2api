# Cline2API v1.2.0

本版聚焦管理后台的可用性、账号运营能力和部署可靠性，并将新版登录界面与本地壁纸资源纳入正式构建。

## 新增与改进

- 新增账号计费与用量面板：订阅计划、额度、个人钱包、近期扣费与缓存状态分开展示。
- 新增账号批量操作：批量删除、分组修改、凭据导出，以及卡片/列表视图、搜索、排序、分页和详情侧栏。
- 普通用户保持只读权限；管理员专属的用户、Key、凭据导出、配置和财务信息接口继续受鉴权保护。
- 登录后台升级为响应式玻璃拟态界面，加入 Tideglass 光晕渐变、颗粒纹理、密码显隐和登录状态反馈。
- 使用本地芙莉莲战斗魔法 4K 壁纸作为登录背景资源，随 Go 二进制嵌入，不依赖额外静态目录。
- 将后台账号、计费和模型管理脚本拆分为嵌入式前端资源，便于维护和缓存。
- 账号文件改用同目录临时文件、同步和原子替换；保存失败时保留原文件并回滚内存修改。
- 增加启动端口冲突、账号管理、计费、存储、认证和流式工具调用回归测试。
- CI 增加独立测试工作流；Docker、桌面端和 CLI 默认统一从 `VERSION` 读取 `v1.2.0`。

## 升级注意

- 升级前备份 `.cline-accounts.json` 及其同目录配置文件；这些文件包含令牌和本地凭据，不会随 Release 提供。
- Docker 用户继续挂载整个 `data/` 目录，以保留原子替换能力。
- 本机初始管理员仍为 `admin / admin`，首次登录后必须修改密码；远程部署请设置 `CLINE_ADMIN_PASSWORD`。
- 新版登录壁纸已打包进服务端，启动后访问 `/admin/` 即可看到；若浏览器仍显示旧页面，请执行硬刷新。
