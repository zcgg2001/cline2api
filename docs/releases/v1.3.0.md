# Cline2API v1.3.0

新增账号批量禁用与重新启用功能。

## 功能

- 账号管理页勾选账号后，选择「禁用所选」或「启用所选」并执行；支持跨页选择及选择全部筛选结果，每次最多 1000 个账号。
- 新增「已禁用」状态筛选和状态标识，账号详情支持单个启用/禁用。
- 禁用账号停止参与新请求调度，保留凭据、订阅、冷却和历史统计；已经开始的请求可继续完成。
- 禁用状态保存到账号文件，重启、刷新凭据或健康状态恢复不会自动启用。
- 启用后仅订阅已确认且状态活跃的账号恢复调度，不强行清除过期或冷却状态。
- 批量接口仅管理员可用；选择失效或保存失败时整批不生效，避免只修改部分账号。

## 验证

- `make check`：Go 测试与竞态检测、前端测试、JavaScript 语法检查、`go vet` 和构建。
- 覆盖三种 API 协议下的禁用与恢复调度、持久化、权限、保存失败回滚及跨页批量操作。
- GitHub Actions 构建 Windows、macOS Apple Silicon 和 Linux x64 桌面版。
