# Cline2API v1.2.1

这是 v1.2.0 的补丁版本，修复管理后台未登录访问时的鉴权闪屏。

## 修复

- 服务端在返回 `/admin/` HTML 前校验 HttpOnly 会话 Cookie。
- 未登录用户只收到登录页 HTML，不会先收到管理后台 DOM 或初始化脚本。
- 管理后台 HTML 使用 `private, no-store` 缓存策略，避免浏览器或共享缓存复用错误页面。
- 登录页保留独立的最小脚本，登录成功后重新请求服务端页面。

## 验证

- `go test ./...`
- `make build`
- `git diff --check`
- GitHub Actions 自动构建 Windows、macOS Apple Silicon 和 Linux x64 桌面版。
