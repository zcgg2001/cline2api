# Cline2API v1.3.1

发布账号批量禁用与重新启用功能，并修复服务关闭后冷却恢复任务仍在运行的问题。v1.3.0 的发版检查发现竞态，未生成 Release；其 tag 保留原样，本次使用新版本号发布修复。

## 功能

- 账号管理支持「禁用所选」「启用所选」、跨页选择及选择全部筛选结果，每次最多 1000 个账号。
- 新增「已禁用」状态筛选、状态标识和详情页单个启用/禁用入口。
- 禁用账号停止参与新请求调度，保留凭据、订阅、冷却和历史统计；重启、刷新凭据或健康恢复不会自动启用。
- 启用不会强行清除过期或冷却状态。批量接口仅管理员可用，选择失效或保存失败时整批不生效。

## 修复

- 冷却恢复任务随代理服务退出而停止，并等待正在执行的检查结束，避免重启服务后残留重复巡检任务。
- 协议测试等待服务及恢复任务全部退出后再还原全局状态，修复随机测试顺序下的竞态。

## 验证

- `make check`：Go 测试与竞态检测、前端测试、JavaScript 语法检查、`go vet` 和构建。
- 使用 v1.3.0 CI 失败时的随机种子复验，覆盖后台任务退出及三种协议下禁用/启用的调度行为。
- GitHub Actions 构建 Windows、macOS Apple Silicon 和 Linux x64 桌面版。

## 回退

旧 tag、Release 和资产保持不变。运行旧版本或撤销功能时，参见 [开发与回退](../development.md)。回退到 v1.2.1 或更早版本前应备份运行数据；这些旧版不识别手动禁用开关。
